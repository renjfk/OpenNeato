### New Features
- Add mDNS local discovery so OpenNeato is easier to find on your network, no IP-address scavenger hunt required (17887a4)
- Add automatic robot restart options, including restart before scheduled cleaning, to help wake up robots that occasionally decide their shift is optional (410428e)
- Add internationalization across the web UI, so OpenNeato can speak a little more like home (aef220e)
- Show the next scheduled cleaning on the dashboard, because the robot's upcoming plans should not be a mystery (e049f34)
