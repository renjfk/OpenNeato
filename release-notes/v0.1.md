Initial release of OpenNeato — an open-source replacement for Neato's discontinued cloud and mobile app.

### Features

- Dashboard with live robot status, battery level, cleaning state, WiFi signal, and storage usage
- House and spot cleaning with pause/resume/stop/dock controls
- Manual driving mode with virtual joystick, live LIDAR map, and motor toggles
- Live cleaning map with coverage overlay during active sessions
- 7-day cleaning scheduler managed entirely on the ESP32
- Cleaning history with recorded paths, coverage maps, and session stats
- Push notifications via ntfy.sh (cleaning done, errors, alerts, docking)
- OTA firmware updates with SHA-256 download verification and MD5 transfer integrity
- Settings page for hostname, timezone, motor presets, notifications, UART pins, and theme
- Event logging with compressed JSONL files, browsable and downloadable from the UI
- Factory reset via 5-second button hold or from the settings page
- Robot clock sync via NTP, re-syncs every 4 hours
- Flash tool — standalone CLI that auto-detects the USB port, downloads firmware, and flashes
- Safety watchdog — auto-stops wheels on browser disconnect, task and heap watchdogs for hangs
- Crash recovery for orphaned cleaning sessions after unexpected reboots

### Supported Robots

Neato Botvac D3 through D7.
