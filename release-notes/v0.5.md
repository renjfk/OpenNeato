🚨 **This is an intermediary release in preparation for #39 (LittleFS to SPIFFS migration) coming in v0.6. Use the new session import feature to back up your cleaning history sessions now - you will need to restore them after the filesystem change.**

### New Features
- Add ESP32-S3 board support (92ee00f)
- Add cleaning history session import via web UI - import individual .jsonl session files with browser-side validation and streaming heatshrink compression on the ESP32 (c39e473)

### Bug Fixes
- Fix history detail not showing for large compressed sessions (3bdceef)
- Fix out-of-bounds write in heatshrink 32-bit decoder causing decompression corruption (52d28e9)
- Fix flash tool VID/PID case-sensitive comparison on Linux (b8887a8)
- Fix WiFi assistant not starting after flash (8b0cc97)
- Fix checksum lookup failing when OS renames downloaded firmware file (d27d83f)
