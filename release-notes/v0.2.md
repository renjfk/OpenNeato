### New Features
- Support for original ESP32 (D0WD-V3) as an alternative to the ESP32-C3 (9750f03)
- Flash tool prompts for port selection when multiple ESP devices are connected (2f9f1cf)

### Improvements
- Reduce idle serial polling to 30s for lower power consumption (7959247)
- Cleaning history now refreshes immediately when a new session starts (7959247)

### Bug Fixes
- Retry secret key initialization with exponential backoff on boot failure (ddd1988)
